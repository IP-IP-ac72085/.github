<h2>一、报价单要逐项读开</h2>
<p>一张合格的报价单至少写清五件事：地址数量、是否独享、出口线路类型、带宽或流量上限、计费周期。缺哪一项，后面就有一处可以加价。</p>
<p>只写美国住宅IP每月若干元的，通常默认共享、默认按流量、默认不含换IP。等你用起来才发现每一项都要另外买。</p>
<h3>三处常见的文字游戏</h3>
<p>原生和住宅常被混着用；不限流量多在带宽上有限制；免费换IP往往限定每月次数。看到这三个词，追问一句具体口径。</p>
<p>问的时候要落到数字：每月能换几次、超了怎么收费、带宽是共享还是独享。对方答得清楚，报价才值得进入下一轮比较。</p>

<h2>三、头七天验收什么</h2>
<p>第一天记基线：延迟、丢包、ASN、归属地。第三天上业务软件，看登录、上传、视频是否正常。第七天回看有没有断线和地址变化。</p>
<p>验收要留记录。截图、命令输出、时间点都存下来，出问题时这份记录比口头描述有用得多。</p>
<h3>稳定性怎么写进约定</h3>
<p>把在线率、换IP次数、故障响应时间写成条款，比任何宣传语都实在。写不进去的，就按最坏情况预估成本。</p>
<h2>四、长期稳定的三个外部条件</h2>
<p>一是本地出口别乱跳，宽带重拨、热点切换都会让登记的白名单失效。二是别把同一地址挂到太多设备上，并发一超就掉线。三是软件版本别频繁动。</p>
<p>这三条都在你这侧，和买多贵的地址无关。很多不稳定的投诉，查到最后是本地换了网络。</p>
<h2>五、续费与变动</h2>
<p>到期前问清续费价是否和首购一致。不少低价是首期优惠，续费回到原价，年化成本差一截。</p>
<p>线路调整、上游变更、地址回收都可能发生。合同里写明变更提前通知和补偿方式，才有谈判依据。</p>
<h3>什么时候该换服务商</h3>
<p>连续两次线路变更没有提前通知、工单三天不回、续费价翻倍，三条中占两条，换的成本就低于留的成本。</p>

<h2>常见问答</h2>
<h3>长效住宅IP和普通住宅IP价格差多少？</h3>
<p>答：常见差一到三倍。长效静态要锁地址、独占出口，资源占用高；普通住宅多为共享池，按量计费，单价低但地址会变。</p>
<h3>稳定性可以要求写进合同吗？</h3>
<p>答：可以提出，能否接受看服务商。至少把在线率口径、故障响应、换IP次数写进订单备注或聊天记录，留作依据。</p>
<h3>首月便宜、续费变贵是常态吗？</h3>
<p>答：比较常见。判断成本要按续费价算年化，别按首期价算，否则预算会低估。</p>
<h3>延迟两百毫秒算不算高？</h3>
<p>答：跨太平洋链路这个量级属正常。关键看抖动和丢包，忽高忽低比稳定偏高更难用。</p>
